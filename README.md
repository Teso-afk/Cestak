# Cesťák

Mobilní webová aplikace na měsíční „Sběrný příkaz k pracovním cestám“.

- Záznamy cest se ukládají jen v telefonu (localStorage), nikam se neodesílají.
- Dny volna (60% volno / sick day, dovolená, propustka k lékaři) se do formuláře netisknou, jejich součty jsou v záložce Přehled.
- Export formuláře do PDF / JPG s psacím písmem, sdílení přes nabídku iPhonu.
- Instalace: otevřít adresu v Safari → Sdílet → Přidat na plochu.

Písma: Caveat, Oooh Baby, Bad Script, Dancing Script, Comforter, Kalam (SIL Open Font License, Google Fonts).
